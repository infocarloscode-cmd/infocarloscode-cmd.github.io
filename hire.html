Kaxa

Point-of-sale system · built alone · in use since July 2026

Day Express, a supermarket, needed a register that didn't stop selling every time the internet went down, and that handled prices in dollars with a rate that changes every day. I built it as a desktop app: React and TypeScript for the screens, Rust for stock and money. It works offline and syncs with the cloud. Today it runs on 6 devices in two stores.

The part I'm proudest of: one store has a Windows 7, 32-bit computer, so I made a lighter version in plain Rust that runs on it. Updates are built by GitHub Actions and the registers install them on their own.

The code is private because it's a product I sell. Happy to walk you through it on a call.

Tauri · Rust · React · TypeScript · Turso · GitHub Actions

Day Express Delivery

Online ordering app · built alone · in use since July 2026

The same store wanted to take orders online without paying a marketplace. Customers build their order, staff check what's really on the shelf, and only then the customer pays and uploads the receipt. Prices live in dollars, so the store only updates the exchange rate.

It gets around 25 orders a week from 72 registered customers. When it went over Vercel's free limits, I moved it to Render, made it lighter on the database, and switched logins to signed cookies.

Next.js · TypeScript · Prisma · PostgreSQL · Redis

ReArena

Esports tournament platform · co-founder and developer

A platform for amateur VALORANT tournaments. I write the code and my co-founder does the design. Teams sign up, brackets run on their own, and the stream gets a live scoreboard.

The game has no API for the live score, so the overlay reads it from the screen with OCR. Double elimination has more edge cases than I expected, so that logic has 50 test files around it. Our first tournament is on November 23.

Next.js · React · TypeScript · Supabase · Tailwind
